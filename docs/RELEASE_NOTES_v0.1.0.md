# Release Notes｜v0.1.0-mvp

发布日期：2026-10-05

## 版本定位

`v0.1.0-mvp` 是“二流文科生的二手文献引用助手”的第一个作品集 / Demo 基准版本。

这个版本的目标不是覆盖所有学术检索场景，而是完成一条真实可用的最小链路：

> 二手引用 / 转述 + 脚注 + 一手 PDF → 语义候选 → 原页定位 → 高亮 → 人工判断。

---

## 主要能力

- 支持二手引文 / 转述与脚注输入；
- 支持已有一手 PDF 直接核验；
- 支持脚注优先的来源识别 / 定向查找；
- 支持文本层 PDF 本地语义检索；
- 支持扫描 PDF 的 RapidOCR 路径；
- 支持多候选展示，不强制唯一答案；
- 支持 PDF 原页定位、高亮与跨页证据；
- 支持书目信息、版本冲突与可复制引用；
- 支持明确的失败 / 不确定状态；
- 支持结果页直接替换来源 PDF 后重新核验。

---

## 产品原则

### 机器找证据，人做判断

当多个段落都合理相关时，系统负责把它们找出来、保留页码和原页证据；最终选择、解释和评价交给用户。

### 不伪造证据

系统不会：

- 猜页码；
- 把 PDF 顺序页冒充印刷页；
- 把检索分数冒充学术结论；
- 把外文脚注冒充已核验的中文版本；
- 找不到时编造高亮。

### Fresh Case B

- Top-1 已进入强相关区域；
- 定位修复后：恢复 PDF 110 页原页证据。

M3 结论：当前语义检索已达到 MVP 的参考工具标准，不再进行无目标的语义优化。

---

## 关键修复

### Unicode / PDF 文本层定位鲁棒性

真实案例暴露出：语义检索已命中，但 PDF 文本层存在 Unicode 兼容字符，导致候选无法重新贴回原页。

修复：

- 引入 NFKC 兼容归一化；
- 保持规范化字符到原 PDF entry 的坐标映射；
- 保持 ambiguous / unmatched / needs_ocr 的诚实状态；
- 不引入宽松到会误高亮的模糊匹配。

## 已知限制

- 不保证召回所有相关段落；
- 不保证 Top-1 是最终答案；
- 不自动判断二手作者是否曲解一手文献；
- 大型扫描本 OCR 在 CPU 上较慢；
- 真实学术 PDF 不进入公开仓库；
- 当前以桌面端为主，不做移动端适配；
- 来源获取能力受现有合法 / 开放来源约束。

---

## 数据边界

公开仓库只包含：

- 代码；
- 配置；
- 合成 probes；
- 脱敏评测结果；
- 产品 / 工程文档。

真实 PDF、OCR 文本、原页截图和私有评测输出位于 `data/private/`，由 Git 忽略。

---

## 后续原则

这个版本之后不默认继续加功能。

只有真实用户使用暴露出新的主导失败模式，才重新开启：

- 语义检索；
- 来源获取；
- OCR；
- UI；
- 其他新阶段。

否则保持 MVP 冻结，用于 Demo、作品集与求职。
