# Demo 演示指南｜MVP v0.1.0

这份指南只服务一个目标：**在 2–3 分钟内让招聘方看懂产品价值，而不是现场表演工程细节。**

## 推荐演示路线：真实 Weber Golden

这是本机作品集 Demo 的首选路径。

### 演示前 3 分钟准备

1. 进入仓库根目录；
2. 启动本地服务：

```powershell
$env:PQA_HOME = $PWD
.\.venv\Scripts\python.exe tools\mvp_app.py
```

3. 浏览器打开：

```text
http://127.0.0.1:8765/result/ui-golden-preview
```

4. 确认页面能看到：
   - 来源 PDF；
   - 书目信息；
   - 黄色版本冲突提示；
   - 多个候选；
   - 右侧原页高亮；
   - 对应原文；
   - 脚注 / 参考文献复制块。

真实 PDF 和原页截图均位于本机 `data/private/`，不进入 Git。

## 2 分钟标准讲法

### 0:00–0:20｜先讲痛点，不先讲 RAG

> 我做这个工具，是因为人文社科写作里经常会遇到一个很具体的问题：二手作者说“韦伯认为……”，脚注指向一篇外文原作，但真正写论文时，我需要知道中文译本里到底怎么说、在哪一页、上下文是什么。普通聊天模型能给答案，但很难把答案重新钉回一手文献原页。

### 0:20–0:40｜看来源和书目信息

指左侧来源 PDF 和书目信息：

> 所以我的产品不是先生成结论，而是先把“二手转述 + 脚注 + 一手 PDF”组织成一条核查链。版本信息有冲突时不会替用户抹平，而是单独提示。

### 0:40–1:05｜看候选列表

指中间候选：

> 语义检索只负责把几百页缩小到一组值得看的候选。这里我刻意没有把 Top-1 叫做“正确答案”，因为真实评测里正确证据可能在 rank 5、rank 7，甚至一个二手段落会综合多个一手位置。

### 1:05–1:35｜展开右侧证据

切换一个候选：

> 真正关键的是后半段：候选必须重新定位回 PDF 原页，并在原页上高亮。这样用户可以自己核上下文，而不是相信一段 AI 生成文本。

### 1:35–1:55｜强调产品边界

> 如果多个段落都合理相关，我全部给出来，不替研究者判断最终该选哪个、该怎么解释。机器负责找证据，人负责做学术判断。

### 1:55–2:15｜讲真实评测与 Bug

> 我最后没有继续堆 reranker，而是拿新的真实材料做盲测。两个 fresh case 都暴露出同一个 PDF 文本层 Unicode 定位问题：检索找到了，但高亮贴不回原页。修复只改定位层，Fresh A 从 0 个定位恢复到 5 个，Fresh B 恢复到 PDF 110 页，同时六套回归全部通过。

结束。

可以回到：

```text
http://127.0.0.1:8765
```

然后现场输入一条二手转述、脚注并上传本地 PDF。

但不建议把“冷启动索引 60–90 秒”作为主演示流程。主演示优先使用已经跑好的真实结果页；如果面试官关心可复现性，再展示 live rerun。

## 不要现场演示的东西

### 1. 不要现场 OCR 整本扫描书

459 页扫描本在 CPU 上的 OCR 可能接近 1 小时。这是离线预处理能力，不是 2 分钟 Demo 的主角。

### 2. 不要现场讲 10 分钟技术栈

除非对方追问，否则只说：

> PaperQA2 做分块/检索，BGE 做本地中文向量检索，pypdfium2 负责把候选重新定位回 PDF 原页，扫描本有 RapidOCR 路径。

### 3. 不要承诺“自动判真伪”

正确说法：

> 它是 citation verification assistant / evidence retrieval tool，不是自动学术裁判。

---

## 30 秒极简版

如果只有 30 秒：

> 这是一个“二手文献引用核验助手”。我把二手转述、脚注和一手 PDF 输入进去，系统先做语义检索，把几百页缩小到几个候选，再把候选重新定位到 PDF 原页并高亮。真实评测后我把产品原则定成“机器找证据，人做判断”：多个相关段落全部展示，不强行给唯一答案。这个项目最终不是做一个聊天机器人，而是做一条可追溯的学术证据链。

## Public GitHub 如何验证

真实学术 PDF 因版权与隐私不进入仓库。

公开仓库可运行零成本合成探针：

```powershell
$env:PQA_HOME = $PWD
.\.venv\Scripts\python.exe tools\mvp_probes.py
.\.venv\Scripts\python.exe tools\t003_regression_probes.py
.\.venv\Scripts\python.exe tools\t004_regression_probes.py
.\.venv\Scripts\python.exe tools\t006_ocr_probes.py
.\.venv\Scripts\python.exe tools\source_acquisition_probes.py
.\.venv\Scripts\python.exe tools\footnote_first_probes.py
```

这套公开验证与私有真实案例形成两层证据：

- 合成 probes：验证工程契约；
- private real cases：验证产品在真实学术材料上的行为。
